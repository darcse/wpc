# WPC 디자인 기준

Stitch로 만든 디자인 시스템(`DESIGN.md`)과 시안(`mockups/*.html`)을 구현에 쓰기 위한 기준 문서다. **시안은 참고용**이며, 시안의 CDN 스크립트·가짜 데이터·모델에 없는 요소는 가져오지 않는다. 콘텐츠 모델은 `docs/content-model.md`가 원본이다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 색 기준값 | `DESIGN.md` **본문 설명의 값**을 쓴다(바탕 `#0E0E11`, 면 `#17171C`, hover 면 `#1F1F26`, 선 `#27272F`, 본문 글자 `#F4F4F6`, 보조 `#9A9AA6`, 비활성 `#6E6E7C`, 강조 `#A78BFA`, 강조 hover `#C4B5FD`, 민트 `#6EE7B7`, 로즈 `#F472B6`). 상단 frontmatter의 Material 토큰 값은 쓰지 않는다 |
| 모서리 | 전부 0px. 원형은 아바타·재생 표시 같은 실제 원형 요소만 예외 |
| 테마 | 다크 우선 출시. 색은 `표면`, `글자`, `강조` 같은 **역할 이름 토큰**으로 한 곳에 정의해 라이트를 나중에 추가할 수 있게 준비. 라이트는 별도 기능 |
| 언어와 폰트 | 한영 병행. 영문 제목 Playfair Display, 영문 메타·라벨 Space Mono, 영문 본문 Plus Jakarta Sans, 한글은 한글 폰트를 병행(후보는 구현 때 비교). UI 라벨(메뉴 등)은 영문을 유지 |
| 모바일 메뉴 | 상단 메뉴 버튼으로 링크 목록을 열고 닫는다. 하단 탭바는 쓰지 않는다 |
| 모바일 최소 기준 | 본문 16px 이상, 메타 12px 이상(DESIGN.md의 11px 메타는 12px로 올린다), 터치 영역 44px 이상, 입력창 16px 이상, 핀치 확대 허용 |
| 콘텐츠 갱신 | Sanity 웹훅 + 태그 재검증(`docs/webhook-setup.md`) |

## 만들지 않는 것 (시안에 있어도 제외)

로그인, Edit Mode, 프로필, Gear/Audio/Contributor 메뉴, 리비전 로그, 댓글, 기여 콜아웃, VERIFIED/CANONICAL류 뱃지, 가짜 통계와 텔레메트리 바, 하단 고정 오디오 플레이어, 스템·FLAC 재생, CSV/JSON 내보내기, 음향·장비 수치 UI(RT60, dB, 페달 체인 등), 가상의 저자·기여자 이름, 실존 인물의 지어낸 인용.

## 구현 시 지킬 점

- 시안의 Tailwind CDN·Material Symbols·Google Fonts 링크는 쓰지 않는다(`@theme`, `next/font`, 아이콘 라이브러리로 구현).
- 계산 가능한 값(건수, 읽는 시간, 목차, 시대 구간, 릴리스 수)은 저장하지 않고 쿼리로 계산한다.
- `/studio`에는 사이트의 헤더·푸터·폰트·전역 스타일을 적용하지 않는다.
- 이미지가 없거나 값이 비어도 화면이 깨지지 않게 한다.
